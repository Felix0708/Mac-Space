# 여백

**내 Mac의 저장 공간, 어디에 쓰이는지 한눈에.**

여백은 저장 공간 사용량과 큰 폴더를 시각적으로 보여주고, 사용하지 않는 앱을 정리할 수 있도록 돕는 macOS 앱입니다. 앱을 실행하면 자동으로 조사하며, 필요할 때 **재조사**를 눌러 결과를 갱신할 수 있습니다.

<img src="assets/icon.png" alt="여백 아이콘" width="160">

## 주요 기능

- **저장 공간 요약** — 전체·사용·여유 공간을 원형 차트와 숫자로 표시합니다.
- **큰 폴더 확인** — 조사한 항목을 용량순으로 정렬하고 막대로 비교합니다.
- **폴더 탐색** — 하위 폴더를 살펴보고 파일 위치를 Finder에서 확인합니다.
- **앱 정리** — 설치된 앱을 검색하고, 선택한 앱과 관련 파일을 확인한 뒤 휴지통으로 옮깁니다.
- **불완전한 결과 표시** — 접근 제한이나 시간 초과가 있으면 일부 확인 또는 미확인으로 표시합니다.

## 지원 환경

| 항목 | 현재 배포 파일 기준 |
| --- | --- |
| 버전 | 0.2.0 · 빌드 4 |
| 운영체제 | macOS 27.0 이상 |
| 프로세서 | Apple Silicon · M1 이상 |
| 설치 위치 | `/Applications/여백.app` |
| 배포 상태 | 로컬 시험판 · Developer ID 서명 및 Apple 공증 미완료 |

Intel Mac용 빌드는 제공하지 않습니다. 다른 Mac과 여러 macOS 버전에서의 실제 설치·실행은 아직 검증하지 않았습니다.

## 설치

설치 파일은 GitHub 릴리스 첨부파일로 배포할 수 있습니다. 소스에서 직접 생성한 설치 파일은 `dist/`에 저장되며 Git에는 포함하지 않습니다.

### DMG로 설치

1. `Yeobaek-0.2.0-arm64.dmg`를 엽니다.
2. `여백.app`을 옆의 `Applications` 바로가기로 드래그합니다.
3. 응용 프로그램 폴더에 설치된 **여백**을 실행합니다.

DMG 안의 앱을 직접 실행하지 말고 복사한 앱을 사용하세요. 업데이트할 때는 먼저 실행 중인 여백을 종료하세요.

### PKG로 설치

`Yeobaek-0.2.0-arm64.pkg`를 열고 macOS 설치 프로그램의 안내를 따르세요. PKG는 DMG 안에도 포함되어 있습니다.

### 터미널에서 sudo로 설치

DMG를 연 상태에서 다음 명령을 실행합니다.

```bash
sudo /usr/sbin/installer -pkg "/Volumes/Yeobaek/Yeobaek-0.2.0-arm64.pkg" -target /
```

패키지 무결성과 지원 환경을 먼저 확인하는 설치 스크립트도 사용할 수 있습니다.

```bash
sudo /bin/bash "/Volumes/Yeobaek/install-yeobaek.sh"
```

설치 없이 검사만 하려면:

```bash
/bin/bash "/Volumes/Yeobaek/install-yeobaek.sh" --check
```

같은 이름의 디스크 이미지가 이미 열려 있으면 마운트 경로에 숫자가 붙을 수 있습니다. 이 경우 실제 경로에 맞춰 명령을 수정하세요. 스크립트와 PKG를 별도로 다운로드했다면 두 파일을 같은 폴더에 두어야 합니다.

`sudo`는 설치에만 사용합니다. 앱은 일반 사용자로 실행하세요. **sudo 설치가 전체 디스크 접근 권한까지 부여하지는 않습니다.**

## 처음 실행하기

앱을 열면 기본 범위 조사가 자동으로 시작됩니다. 결과는 확인되는 순서대로 표시되며, **재조사**를 누르면 다시 계산합니다.

### 조사 범위

| 모드 | 조사하는 위치 |
| --- | --- |
| 기본 조사 | 보호 폴더를 제외한 홈의 일반 항목, `/Applications`, `/Library/Developer` |
| 전체 조사 설정 후 추가 | 홈의 `Library`, 휴지통, 데스크탑, 문서, 다운로드, 사진·음악·동영상 폴더, `/Library/Application Support`, `/private/var` |

앱 목록에는 `/Applications`와 `~/Applications` 바로 아래의 `.app`을 표시합니다.

**‘전체 조사’는 보호 폴더를 추가하는 모드 이름입니다.** 디스크의 모든 경로를 조사한다는 의미는 아닙니다. 다른 사용자 폴더, 일부 시스템 경로, 외장 디스크, APFS 스냅샷 등은 조사 범위에 포함되지 않습니다.

### 보호 폴더까지 조사하려면

1. 여백에서 **전체 조사 설정 → 권한 설정 열기**를 선택합니다.
2. macOS **시스템 설정 → 개인정보 보호 및 보안 → 전체 디스크 접근 권한**에서 설치된 `/Applications/여백.app`을 추가하고 허용합니다.
3. macOS가 앱 재실행을 요청하면 먼저 재실행합니다.
4. 여백의 **전체 조사 설정 → 설정 완료 · 전체 조사**를 선택합니다.

이 선택은 저장되어 다음 실행과 재조사에도 적용됩니다. 앱의 ‘설정 완료’ 버튼 자체가 macOS 권한을 부여하거나 실제 허용 상태를 검증하는 것은 아닙니다.

보호 영역 조사 중 접근 실패나 시간 초과가 발생하면 해당 범위의 조사를 중단하고 이후에는 기본 범위로 돌아갑니다. 설정을 확인하기 전까지 보호 영역을 계속 자동 재시도하지 않습니다.

## 앱 정리

1. **앱 정리**에서 앱을 검색합니다.
2. **정리 검토**를 눌러 이동할 파일을 확인합니다.
3. 필요한 항목을 선택하고 **휴지통으로 이동**을 확인합니다.

기본 조사에서는 앱 본체만 표시합니다. 전체 조사 설정 후에는 앱 식별자와 정확히 일치하는 일부 캐시·설정·지원 데이터 경로도 확인합니다. 관련 데이터는 기본 선택하지 않습니다.

휴지통은 자동으로 비우지 않습니다. 이동한 파일이 차지하는 공간은 휴지통을 비우기 전까지 반환되지 않을 수 있습니다.

이 기능은 모든 흔적을 지우는 완전 제거를 보장하지 않습니다. 공유 컨테이너, 백그라운드 서비스, 시스템 확장 등은 정리 대상에 포함되지 않습니다. VPN·보안 프로그램·드라이버는 제조사가 제공하는 제거 기능을 우선 사용하세요.

## 용량 표시를 읽는 방법

- 원형 차트는 파일 시스템에서 확인한 전체 사용량을 보여줍니다.
- 폴더 목록은 현재 조사 범위에서 확인한 용량입니다. 전체 사용량과 목록의 합계는 같지 않을 수 있습니다.
- 상단 색상 막대는 **상위 6개 항목 사이의 용량 비율**입니다. 카드 자체의 크기는 동일합니다.
- 용량 뒤의 **`+`**는 일부만 확인했다는 뜻입니다. 실제 용량은 더 클 수 있습니다.
- **미확인**은 확인된 용량이 없다는 뜻이며, 해당 항목이 비어 있다는 뜻은 아닙니다.

APFS 공유 데이터, 스냅샷, 접근 권한, 조사 중 파일 변경 때문에 macOS 저장 공간 화면과 수치가 다를 수 있습니다. 개별 용량 계산에는 20초 제한이 있어 큰 폴더가 일부 결과로 표시될 수도 있습니다.

## 현재 검증 상태

확인한 항목:

- 기본 범위의 실행 시 자동 조사와 재조사
- 저장 공간 및 앱 목록 화면 표시
- 보호 경로 제외 정책과 삭제 범위 제한 검사
- DMG 체크섬, 읽기 전용 마운트 및 포함 파일
- PKG 설치 대상 경로, OS·CPU 조건, 원본 앱과의 일치 여부
- 설치 스크립트의 검사 모드, 패키지 누락·변조 시 실행 차단

아직 검증하지 않은 항목:

- 실제 앱·개인 데이터 삭제
- 전체 디스크 접근 권한 부여 후의 전체 조사 흐름
- PKG를 이용한 실제 설치 및 다른 Mac에서의 설치·실행

현재 앱은 로컬 ad-hoc 서명 시험판입니다. **Developer ID 서명과 Apple 공증 전이므로 다른 Mac에서 다운로드해 열면 보안 경고나 실행 차단이 발생할 수 있습니다.** 설치 스크립트는 macOS 보안 기능이나 개인정보 보호 설정을 변경하지 않습니다.


## 개발 및 빌드

Apple Silicon Mac, macOS 27 SDK를 포함한 Xcode, Python 3가 필요합니다.
프로젝트 루트에서 실행하세요. 기존 앱이나 `dist/` 폴더가 없는 상태에서도 빌드할 수 있습니다.

```bash
# 앱 생성: dist/여백.app
bash scripts/build.sh

# 실제 앱 코드를 사용하는 경계 검사
bash scripts/test.sh

# DMG, PKG, sudo 설치 스크립트 생성
python3 scripts/package.py

# 패키지 내용과 DMG 읽기 전용 마운트 검사 (실제 설치하지 않음)
python3 scripts/verify-package.py
```

빌드·패키징은 sudo 없이 실행합니다. sudo는 생성된 패키지를 설치할 때만 필요합니다.
빌드 결과는 로컬 ad-hoc 서명이며 Developer ID 서명·Apple 공증은 수행하지 않습니다.

## 프로젝트 구조

```text
src/        앱 화면과 조사·정리 로직
resources/  Info.plist와 macOS 아이콘
assets/     아이콘 PNG 원본
scripts/    빌드·테스트·패키징 스크립트
tests/      앱 로직 경계 검사
.build/     컴파일 캐시 및 임시 파일 — Git 제외
dist/       실행 앱과 설치 파일 — Git 제외
```

실제 사용자 화면·용량 기록·개인 경로가 담긴 로그는 저장소에 포함하지 않습니다.
